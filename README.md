1. 打开小程序、安卓或桌面端
2. 在豆包里复制分享链接
3. 粘贴后点「一键快速提取」
4. 预览无水印结果，保存到相册、复制下载地址，或提取音频

视频较大时，用「复制地址」到浏览器、桌面端或安卓下载。

## 常见问题

**链接复制对了，仍然解析失败**

完整分享链接才能解析。过期、已删除，或需要登录才能查看的内容，会解析失败。豆包请在分享面板里复制链接。

**小程序里视频保存失败**

微信对小程序下载有体积上限。点「复制地址」，用浏览器、桌面端或安卓保存。

**桌面端登录**

用邮箱登录或注册，流程与官网相同。注册成功赠送 100 次额度。
